3. AT API SURFACE ACTUALLY USED BY AG (from ShellConnection.kt +
   AndroidShellToolImpl.kt):
   - AtRuntime.initialize(context)
   - AtRuntime.connectAuto(keyDir)
   - AtRuntime.readinessState()
   - AtRuntime.disconnect()
   - AtRuntime.execute(command, timeoutMs)   [one-shot; no-replay hard rule:
       one ToolCall performs at most one execute()]
   NOT used (present in AT Handoff V1 bundle but unconsumed by AG today):
   - persistent TerminalSession API (raw byte stream, input, resize, Ctrl-C)
   - multi-session
   - transport-loss / recovery callbacks (surfaced only via readiness state)
   => AT HAS CAPABILITY != AG TOOL CONSUMES CAPABILITY
