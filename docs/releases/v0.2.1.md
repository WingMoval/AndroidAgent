# AndroidAgent v0.2.1

**Date:** 2026-11-18
**Previous release:** [v0.2.0](https://github.com/WingMoval/AndroidAgent/releases/tag/v0.2.0)

## Highlights

v0.2.1 is a compatibility patch release focused on **provider/model selection
semantics** and **home UI layout**. It upgrades in place from v0.2.0 (same
package, same signing identity) with no data migration required.

### Configured vs Discovered Models

- The **main model picker** now shows only models you have explicitly
  configured. The provider's full `/models` catalogue is no longer mixed in.
- **Add Model** is the only place where the provider's discovered catalogue
  is reachable. Discovery results are not auto-configured and do not change
  your active model.

### Provider-aware Model Selection

- A model's identity is now **(Provider, model ID)**, so the same model ID can
  exist on different providers without conflict.
- **Add Model** flow: **Select Provider → Discover → Select Model → Optional
  Alias → Add to that provider**. The provider selector is always shown, even
  when only one provider profile is configured.
- Discovery always uses the **selected provider's** endpoint and API key —
  never the currently active provider's.
- Adding a model to a provider does **not** switch your active provider or
  active model.
- Switching to a model on a different provider atomically applies that
  provider's credential + model.

### Model Aliases & Management

- Each configured model has an optional **alias** (display name). The alias
  affects only the UI; the full model ID is always sent to the API.
- **Rename** an existing model's alias from the picker (long-press → Rename).
- **Remove** a configured model (long-press → Remove). The currently active
  model is protected from removal.

### Home Model Status

- The current **Provider · Model** display moved from the message composer row
  to a lightweight row **directly above** the composer (no border, no card, no
  background).
- Display format: `ProviderDisplayName · ModelDisplay`, e.g.
  `OpenRouter · deepseek-v4-flash-0731` or `OpenRouter · V4 Flash` (with
  alias).
- The composer row is now a pure input row: `[+] [Message] [Send/Stop]`.
- Default model display uses the model ID **suffix** after the last `/`
  (e.g. `deepseek/deepseek-v4-flash-0731` → `deepseek-v4-flash-0731`) instead
  of the provider prefix.

## Upgrade Notes

- **In-place upgrade** from v0.2.0: `adb install -r` (same signing identity).
  No uninstall required.
- Existing provider config (endpoint, API key, selected model) is preserved.
- A legacy single-model config (no `configuredModels` field) is
  automatically normalized to a one-element configured set — no
  re-configuration needed.
- Durable sessions and history are preserved.

## Compatibility

- **OpenAI-compatible architecture.** Any provider exposing an
  OpenAI-compatible chat-completions `/models` + `/chat/completions` API can
  be configured.
- **OpenRouter has been real-device verified.** Other OpenAI-compatible
  providers are architecturally supported but have **not** been individually
  real-device verified.

## Known Limitations

- There is no "Add Provider" UI in this release. Provider profiles are
  managed through the existing Provider Settings surface. Built-in provider
  templates / marketplace are not implemented.
- ADB / AT (AndroidTerminal) execution semantics are unchanged from v0.2.0.

## Install

1. Download `AndroidAgent-v0.2.1-release.apk` from this release.
2. Verify the SHA256 (below) and the signing certificate.
3. Install or upgrade: `adb install -r AndroidAgent-v0.2.1-release.apk`.
