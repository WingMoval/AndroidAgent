============================================================
Track A: Transcript Cards
============================================================

TRANSCRIPT_RENDERER_BEFORE = single TextView (TranscriptModel.render() → one string)
TRANSCRIPT_RENDERER_AFTER = RecyclerView + TranscriptCardAdapter (per-block cards)

依赖新增:
  androidx.recyclerview:recyclerview:1.3.2
  WHY_REQUIRED: single TextView cannot support per-block Copy/Retry/collapse
  DEPENDENCY: androidx.recyclerview 1.3.2 (stable)

Card Types:
  UserCard         = "You" label + text + Copy + Retry + More (Copy/Edit&Resend)
  ThoughtCard      = "Thought"/"Thinking..." label + text + Copy + collapse (>200 chars)
  AssistantCard    = "Assistant" label + text + Copy + Retry (origin User)
  ToolExecutionCard= "Shell" + "Result" (two blocks, visually grouped)
  FailureCard      = "Failed" label + text + Copy + Retry
  InterruptedCard  = "Stopped" label + text + Copy + Retry

Per-block Copy:
  ClipboardManager.setPrimaryClip(ClipData.newPlainText("Transcript", blockText))
  只复制当前 block 正文, 不复制整个 transcript

Retry 语义:
  UI 按钮 "↻" → 找 originating User text (backward scan) → HostActions.send(text)
  作为新 User Turn 发送, 旧历史不删除不修改
  RETRY_CREATES_NEW_TURN = YES
  RETRY_MUTATES_HISTORY = NO
  Active Run 时: Retry 按钮 GONE (isBusy 检查)

Edit & Resend:
  UserCard More → "Edit & Resend" → input.setText(oldText) → 用户编辑 → Send
  不修改旧 durable Message

Thought collapse:
  >200 chars: 显示前 200 + "Show more" / "Show less"
  Thinking→Thought: 同一 Card (phase flip, 不新建 block)

Result collapse:
  >300 chars: 显示前 300 + "Show more" / "Show less"
  上游 truncation 不伪造 "展开完整"

NATIVE_SELECTION:
  card_body.setTextIsSelectable(true) 所有内容 Card
