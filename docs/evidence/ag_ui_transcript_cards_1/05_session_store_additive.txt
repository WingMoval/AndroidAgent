TopicSessionStore (ag-runtime)
============================================================

新增接口方法:

语义:
  - 返回所有 durable session summaries
  - 按 last_used_at DESC 排序 (最近使用在前)
  - 空 DB 返回 emptyList
  - 不改变现有方法语义

ADDITIVE: 不影响 createSession / appendMessage / loadSession 等。

============================================================
RoomTopicSessionStore (app)
============================================================

实现:
  override suspend fun listSessions(): List<TopicSessionRecord> =
      try {
          sessionDao.listAll().map { it.toRecord() }
      } catch (e: Exception) {
          throw PersistenceException(e, category = "list_sessions_failed")
      }

错误处理:
  - DAO 异常 → PersistenceException
  - 不静默吞掉错误
