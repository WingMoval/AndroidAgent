The adapter's data model IS correct (blocks = []).
The RecyclerView IS NOT updated to reflect the empty state.

This is a classic RecyclerView notification bug:
  - notifyItemRangeChanged(0, N) updates N existing items
  - notifyItemRangeChanged(0, 0) is a no-op (zero-length range)
  - To REMOVE items: notifyItemRangeRemoved or notifyDataSetChanged
