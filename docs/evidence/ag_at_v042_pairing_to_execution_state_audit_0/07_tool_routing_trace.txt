=== ROUTING DECISION POINT ===

The FIRST routing decision is in AdbOneShotBackend.ensureConnected() line 64:
  if (AdbRuntime.activeTransport == AdbTransportMode.LOCAL && AdbEngine.localhostConnected())

This reads:
  1. AdbRuntime.activeTransport (Kotlin var, NO @Volatile)
  2. AdbEngine.localhostConnected() (JNI, g_local_mutex)

If BOTH true → LOCAL path (executeShellLocalhost)
If EITHER false → falls through to Wireless path (executeShell)

=== IN OUR TRACES ===

The log shows "AdbNative.executeShell" (Wireless JNI), NOT "executeShellLocalhost".
This means ensureConnected() returned false (or the code took the Wireless path).

The "local transport loss" log at T17 confirms onOperationResult was called,
which means executeShell (Wireless) was called and failed.

=== WHY ensureConnected() RETURNED FALSE ===

Two possibilities:
  A. activeTransport was read as WIRELESS (stale, cross-thread visibility)
  B. localhostConnected() returned false (unexpected, since isOnline() should be true)

Possibility A is the most likely: the CLI bridge worker thread (10602)
read the initial value (WIRELESS) instead of the updated value (LOCAL)
written by the IO thread (9047).
