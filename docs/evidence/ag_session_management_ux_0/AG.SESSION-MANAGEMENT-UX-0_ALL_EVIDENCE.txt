=====================================================

Core contract: NO USER MESSAGE = NO SESSION

Architecture:
  - AgentRuntime.enterBlankDraft() (non-suspend) replaces old newSession()
  - Draft hydrates Core under placeholder DRAFT_CORE_ID="__blank_draft__"
  - sessionId=null, blankDraft=true
  - send() materializes: materializeDraft() creates durable row
    (title=normalized first msg, origin=AUTO_FIRST_MESSAGE)
    then restoreSession(id, emptyList()) so Core's D1 commits the
    user message to the real session (two-step ordering avoids the
    empty-history-UNRECOVERABLE trap)

  messageDurability.commit(session.id, userMsg) happens BEFORE
  modelProvider.complete (AgentCore.kt ~L349-356)

    id TEXT PRIMARY KEY
    title TEXT (nullable)
