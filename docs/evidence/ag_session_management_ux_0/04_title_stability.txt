Title auto-updates ONLY ONCE (at materialization time).
Subsequent messages do NOT trigger a title update.
The title_origin remains AUTO_FIRST_MESSAGE (0) until
the user explicitly renames (which sets it to USER_RENAMED=1).

Title ownership rule:
  - AUTO_FIRST_MESSAGE: set at creation, never auto-changed
  - USER_RENAMED: set by manual rename, wins permanently
  - No LLM-based title generation
  - normalizeTitle = trim + collapse whitespace only
