AG.UI-TRANSCRIPT-CARDS-1 — Card Mapping

日期: 2026-10-27

============================================================
Block → Card Mapping
============================================================

TranscriptModel.Block.User
  → UserCard
  Label: "You"
  Body: block.text
  Actions: Copy, Retry, More (Copy / Edit & Resend)
  Selection: textIsSelectable = true

TranscriptModel.Block.Thinking (phase=THINKING)
  → ThoughtCard (running)
  Label: "Thinking..."
  Body: block.text (live reasoning)
  Actions: Copy
  Selection: textIsSelectable = true

TranscriptModel.Block.Thinking (phase=THOUGHT)
  → ThoughtCard (completed)
  Label: "Thought"
  Body: block.text
  Actions: Copy
  Collapse: >200 chars → truncate + "Show more" / "Show less"
  Selection: textIsSelectable = true
  注意: THINKING → THOUGHT 是同一个 Card (phase flip)，不新建 block。

TranscriptModel.Block.Assistant
  → AssistantCard
  Label: "Assistant" (final=true) / "Assistant..." (streaming)
  Body: block.text
  Actions: Copy, Retry (origin User text)
  Selection: textIsSelectable = true
  注意: 中间 Assistant formal output 保留 (不只显示 final)。

TranscriptModel.Block.Shell
  → ToolExecutionCard (command part)
  Label: "Shell"
  Body: "$ " + block.command
  Actions: Copy (copies command only)
  Selection: textIsSelectable = true

TranscriptModel.Block.Result
  → ToolExecutionCard (result part)
  Label: "Result"
  Body: block.text
  Actions: Copy
  Collapse: >300 chars → truncate + "Show more" / "Show less"
  Selection: textIsSelectable = true
  注意: Shell + Result 视觉合并为 ToolExecutionCard，
  但底层 Block 仍保持两个。

TranscriptModel.Block.Failure
  → FailureCard
  Label: "Failed"
  Body: block.text (具体安全错误原因)
  Actions: Copy, Retry (origin User text)
  Selection: textIsSelectable = true
  注意: Run/Provider Failure 单独 Card。
  Tool failure 优先留在 ToolExecutionCard Result。

TranscriptModel.Block.Interrupted
  → InterruptedCard
  Label: "Stopped"
  Body: block.text
  Actions: Copy, Retry (origin User text)
  Selection: textIsSelectable = true
  注意: 不能渲染为 "Failed"。

AG.UI-TRANSCRIPT-CARDS-1 — Copy / Retry / Edit & Resend

日期: 2026-10-27

============================================================
Copy
============================================================

实现: ClipboardManager
  val clipboard = context.getSystemService(Context.CLIPBOARD_SERVICE) as ClipboardManager
  clipboard.setPrimaryClip(ClipData.newPlainText("Transcript", text))

范围: 只复制当前 block 正文
  User: block.text
  Thought: block.text
  Assistant: block.text
  Shell: block.command (只复制命令，不复制 "$ " 前缀)
  Result: block.text
  Failure: block.text
  Interrupted: block.text

不自动复制整个 transcript。

============================================================
Retry / "重做"
============================================================

UI: "↻" icon (ic_menu_rotate)
内部语义: Retry / Re-run originating User Turn
不是: Strict Redo / History rollback / Undo / Rewind

行为:
  1. 点击 Retry 按钮
  2. findOriginUserText(position): 向后扫描找 nearest User block
  3. onRetry(originText) → ChatActivity.retrySend(text)
  4. retrySend → HostActions.send(text)
  5. 作为新 User Turn 发送
  6. 旧历史不删除、不修改

RETRY_CREATES_NEW_TURN = YES
RETRY_MUTATES_HISTORY = NO

范围:
  UserCard Retry: 直接发送 block.text
  AssistantCard Retry: 找 origin User → send
  FailureCard Retry: 找 origin User → send
  InterruptedCard Retry: 找 origin User → send

Active Run 时:
  isBusy = true → Retry 按钮 GONE
  不允许第二个 active Run。

文案:
  accessibility / More 文案: "重新发送为新一轮"
  避免用户误以为是回滚历史。

============================================================
Edit & Resend
============================================================

触发: UserCard More → "Edit & Resend"
行为:
  1. 读取旧 User text
  2. input.setText(oldText) — 放回 Composer
  3. input.setSelection(text.length)
  4. input.requestFocus()
  5. 用户编辑
  6. 点击 Send → 生成新 UserMessage

禁止: 修改旧 durable Message。

============================================================
More Menu
============================================================

UserCard More (ic_menu_more):
  PopupMenu:
    - Copy → copyToClipboard(userText)
    - Edit & Resend → onEditResend(userText)

其他 Card 无 More 菜单。

AG.UI-TRANSCRIPT-CARDS-1 — Session Switch Runtime

日期: 2026-10-27

============================================================
AgentRuntime.switchSession (ADDITIVE)
============================================================

签名:
  suspend fun switchSession(targetSessionId: String): Boolean

规则:
  1. if (isBusy) return false
     - Active Run 时 reject，不能强制切换。
  2. if (startupState != READY) initialize()
     - 必须先 READY。
  3. val record = store.loadSession(targetId) ?: return false
     - 验证 target session 存在于 durable store。
     - 不存在 → reject。
  4. restoreExistingSession(targetId)
     - 复用现有恢复语义:
       - load durable messages
       - controlled repair if required (dangling tool calls)
       - hydrate Core
  5. sessionId = targetId
  6. return true

旧 session:
  - 保留在 store + Core
  - 不删除、不修改
  - SESSION_ROW_EXISTS_BEFORE_CURRENT 不变量保持

ADDITIVE:
  - 不修改 initialize() / newSession() / send() / stop()
  - 不重开 TopicSession domain / persistence semantics / Run durability

============================================================
HostActions.switchSession (SHARED ENTRY)
============================================================

签名:
  suspend fun switchSession(sessionId: String): SessionSwitchResult

行为:
  1. val r = SessionHolder.runtime ?: return Rejected("runtime not ready")
  2. if (r.isBusy) return Rejected("busy")
  3. val switched = r.switchSession(sessionId)
  4. if (switched):
     - SessionHolder.projectCurrentHistory()
     - SessionHolder.setRunStatus("Switched to session.")
     - SessionHolder.notifyUiUpdate()
     - return Ok(sessionId)
  5. else: return Rejected("session not found")
  6. catch (e: Exception): return Rejected("switch failed")

Shared entry:
  UI sidebar click ─┐
                    ├→ HostActions.switchSession
  Debug (future) ──┘
                    ↓
          AgentRuntime.switchSession

不能两套实现。

============================================================
SessionSwitchResult
============================================================

sealed interface SessionSwitchResult {
    data class Ok(val sessionId: String) : SessionSwitchResult
    data class Rejected(val reason: String) : SessionSwitchResult
}

============================================================
HostActions.listSessions
============================================================

签名:
  suspend fun listSessions(): List<SessionSummary>

行为:
  1. val store = SessionHolder.topicSessionStoreRef ?: return emptyList()
  2. store.listSessions().map { SessionSummary(...) }
  3. catch (e: Exception): return emptyList()

Shared entry (与 switch 相同)。

============================================================

  val topicSessionStoreRef: TopicSessionStore? get() = topicSessionStore

允许 HostActions 访问 store (不直接暴露 private field)。
